# Second Brain — public summary

An aggregated weekly view of a personal knowledge pipeline.

**This repository contains structure and totals only.** Session content, quoted
statements, project names, person names, and individual findings are withheld by
design. The full report stays local.

## Regenerating

```sh
python3 sanitize.py    # writes maps/index_public.html
```

## What is deliberately excluded

- Session titles and quoted statements
- Concept labels (they name internal projects)
- Finding details and evidence
- File paths and identifiers

Published automatically by the weekly pipeline.
